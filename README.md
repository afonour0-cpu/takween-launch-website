# TAKWEEN — تكوين | موقع الإطلاق (Launch Website)

موقع تعريفي **عربي أولًا (RTL)**، هادئ ودافئ وفاخر، مبني بـ HTML و CSS و JavaScript بسيط
بلا أي مكتبات خارجية. الغرض من هذه المرحلة: بناء الترقّب وجمع **قائمة الانتظار** — لا متجر
إلكتروني نشط.

> تفاصيل تُصنع لتبقى

## الحالة
- **موقع إطلاق** — ليس متجرًا إلكترونيًا.
- **جاهز مستقبلًا للتجارة الإلكترونية، لكنها غير مُفعّلة** في هذه النسخة.
- لا سلة، لا دفع، لا حسابات، لا مخزون، ولا تقييمات/إحصاءات.

## التشغيل محليًا
افتحي `index.html` في أي متصفح حديث — لا حاجة لخادم أو خطوة بناء. أو شغّلي خادمًا بسيطًا:

```
python3 -m http.server 8080
```
ثم افتحي `http://localhost:8080`.

## الصفحات
- `index.html` — الرئيسية (هيرو · العائلات · المناسبات · خيارات · التخصيص · **قائمة الانتظار** · تعريف بالمدونة · تواصل)
- `about.html` — عن تكوين
- `families.html` — العائلات: **تصميم · تراث · لقطة** (وتكوين برو كخط مستقبلي غير نشط)
- `occasions.html` — المناسبات
- `personalization.html` — الطلبات الخاصة (تُستقبل يدويًا عند الإطلاق)
- `contact.html` — تواصلي / قائمة الانتظار
- `blog.html` · `article.html` · `recipe.html` — المدونة وقوالبها (مُبقاة في المشروع، بعيدة عن
  واجهة الإطلاق: غير مربوطة بالقائمة العلوية، ويصلها رابط ثانوي من التذييل فقط)

## الملفات
- `style.css` — نظام التصميم الكامل (ألوان، خطوط، مكوّنات، تجاوب)
- `script.js` — قائمة الجوال، المفاتيح البصرية، الوضع الليلي/النهاري، نماذج تجريبية (واجهة فقط)
- `assets/takween-logo.png` — الشعار المعتمد (خلفيات فاتحة)
- `assets/takween-logo-ivory.png` — نسخة عاجية (خلفيات داكنة / الوضع الليلي)
- `assets/takween-logo-original.png` — الملف الأصلي كما رُفع

## ما يبقى غير نشط لكنه جاهز للمستقبل
- **قائمة الانتظار / نماذج التواصل** — واجهة فقط (بلا خادم أو دفع)؛ تُربط بخدمة بريد/CRM لاحقًا.
- **زر واتساب العائم** — لا يظهر إلا بعد ضبط رقم حقيقي في `TAKWEEN_CONFIG` داخل `script.js`
  (لا يُعرض رقم مبدئي في الواجهة العامة).
- **TAKWEEN PRO** — خط مهني مستقبلي، معروض بوضوح كـ«غير نشط عند الإطلاق».
- **الطلبات الخاصة** — تُستقبل يدويًا عند الإطلاق (لا مُكوّن طلب تفاعلي).

## عناصر نائبة تُستبدل قبل الإطلاق
كل بيانات التواصل معلّمة **«يوضع لاحقًا»** (واتساب · البريد · إنستغرام · الموقع) — لا أرقام أو
بريد أو روابط وهمية في الواجهة. استبدليها بقيم حقيقية قبل النشر:
- رقم واتساب: `TAKWEEN_CONFIG.whatsappNumber` في `script.js` (أرقام فقط بصيغة دولية بلا +).
- البريد / إنستغرام / الموقع: في التذييل وصفحة التواصل.
- الصور: استبدلي مربعات `<div class="ph">…</div>` بوسوم `<img>` عند توفر التصوير الحقيقي.

## الجوال والحركة
مصمم بمنهجية «الجوال أولًا»، متجاوب من ٣٦٠px حتى المكتب، **بلا تمرير أفقي**. تُحترم
`prefers-reduced-motion`، وتُبسَّط الخلفية المتحركة على الأجهزة الأقل أداءً. لا تشغيل فيديو
تلقائي بصوت.

## النشر
الموقع ثابت بالكامل — ارفعي محتويات المجلد كما هي إلى أي استضافة ثابتة (Netlify / Vercel /
Cloudflare Pages / GitHub Pages). لا متغيرات بيئة ولا خطوات بناء.
